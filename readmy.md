# Notes — голосовые заметки

Приложение для голосовых заметок: диктуешь с ПК или телефона, текст
сохраняется в базу на Raspberry Pi. Сервер и БД крутятся в Docker.

## Что внутри

- **db** — PostgreSQL 16, хранит заметки.
- **api** — FastAPI, принимает и отдаёт заметки по HTTP.

Оба сервиса в одной docker-сети. API ходит к базе по имени `db:5432`.
Наружу открыты порты: `5432` (база, для DBeaver) и `8000` (API).
