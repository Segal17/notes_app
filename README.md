# Notes App — заметки и инвентаризация семян

Веб-приложение на Python (FastAPI + Jinja2) с PostgreSQL.
Две вкладки: **Заметки** (дневник по культурам) и **Семена** (инвентаризация).

## Что умеет

### Вкладка «Заметки» (/)
- Форма: дата + несколько строк (Культура + Описание).
- Голосовой ввод в описание (Web Speech API, кнопка 🎤 → ⏹).
- «+ Добавить запись» — новая строка (по умолчанию 2 пустые).
- «Сохранить» — отправить все непустые строки за выбранную дату.
- «Показать историю» — загрузить последние записи в те же поля.
  - В истории дата только для чтения.
  - У каждой строки кнопка «✎ Изменить» → правишь → «✓ Сохранить» →
    подтверждение → обновляется только эта запись (дата не меняется).
- Кнопка «?» — короткое описание, зачем нужны заметки.
- История отсортирована по дате **по возрастанию** (старые сверху).

### Вкладка «Семена» (/second)
- Инвентаризация семян по годам.
- Выбор года в заголовке (выпадающий список, по умолчанию текущий).
- Под культурой — бейджи: срок годности, потребность, коэффициент
  (свойства культуры, хранятся в справочнике `cultures`).
- Таблица сортов: Сорт + Остаток (число + единица: г, шт, кг…).
- Форма «Добавить запись»: год, культура (из справочника), сорт,
  остаток, единица остатка.

### Общее
- Светлая / тёмная тема (кнопка 🌙/☀️ в шапке, сохраняется в localStorage).
- Мобильная адаптация (карточки, крупные кнопки).
- Тосты сверху (успех/ошибка).

## Стек

- **Python 3.12+**
- **FastAPI** + **uvicorn** — веб-сервер
- **Jinja2** — HTML-шаблоны
- **PostgreSQL 16** — база (в Docker на малинке/ПК)
- **psycopg 3** — драйвер БД
- **JS** — Web Speech API (голос), fetch (без перезагрузки), localStorage (тема)
- **Bootstrap Icons** (CDN) — иконки

## Запуск (Windows, локально)

1. Установи Python 3.12+, PostgreSQL (или Docker с Postgres).
2. Создай `.env` в корне (значения — свои):

```
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=notes
DB_USER=change_me
DB_PASSWORD=change_me
```

3. Запусти:

```powershell
.\run_web.bat
```

Скрипт создаёт `.venv`, ставит зависимости, запускает uvicorn на
`http://0.0.0.0:8000`.

4. Открой `http://localhost:8000`.

## База данных

Таблицы:

- **`notes`** — заметки: `id, created_at, date, culture, description`
- **`cultures`** — справочник культур:
  `id, name, expiry_text, need, need_unit, coefficient`
- **`seed_inventory`** — семена по годам:
  `id, year, culture, sort, quantity, quantity_unit, created_at`

SQL-файлы — в `sql/`. Применяются вручную (DBeaver или psql):

```powershell
psql -h 127.0.0.1 -U change_me -d notes -f sql/001_seed_inventory.sql
psql -h 127.0.0.1 -U change_me -d notes -f sql/002_cultures.sql
```

(или через DBeaver: открыть файл и выполнить)

## Голосовой ввод

- Работает **на `localhost`** (с ПК, где запущен сервер) — по HTTP.
- С телефона/другого устройства по `http://192.168.x.x:8000` — **не работает**
  (браузер требует secure context).
- Решения: **Tailscale** (`tailscale serve --bg 8000` → `https://<name>.ts.net`),
  **mkcert** (локальный CA + установка на телефон),
  или **хостинг под домен** (Railway/Render/VPS + Caddy).
